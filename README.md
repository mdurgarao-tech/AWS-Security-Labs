# AWS Security Labs

Notes and lab write-ups on securing AWS networking and access. I hold the AWS Certified Security – Specialty (SCS-C02) certification, and this repo is where I keep my study notes and practice labs. It is a work in progress.

## Topics

- **VPC design:** public and private subnets, route tables, internet gateway and NAT paths
- **Network access controls:** Security Groups (stateful) vs Network ACLs (stateless), and how they layer
- **IAM:** least-privilege policies, roles, and the Effect/Action/Resource structure
- **Logging:** VPC Flow Logs and CloudWatch for visibility

## Status

The repo currently contains this README and a license. Notes and lab write-ups will be added under one folder per topic as I finish them. Nothing here is from a production environment.

## Notes

- Any labs are built in a personal test account. Account IDs, ARNs and resource names are removed before anything is published.
- IAM policy examples are illustrative. Review and scope them before using them anywhere real.
